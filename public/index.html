05 / QUICK GUIDE✧ HOW IT WORKS

      
Bắt đầu thật
nhẹ nhàng.
  1. 01Nhập thông tin tài khoản OLM tại khu vực đăng nhập.
  2. 02Sử dụng các module khi backend/API đã được cấu hình.
  3. 03Cuộn lên hoặc xuống để di chuyển giữa các phần.

      
Ghi chú kỹ thuật
Backend Netlify xử lý các route /login, /logout và /session. Cần cấu hình URL API OLM đáng tin cậy trong biến môi trường Netlify. Các module bài tập/đáp án vẫn cần API riêng tương thích.
